# Skill: Wiki Ingest

## Purpose

把一份 raw note 轉成可回源、可檢索、可長期整理的 wiki 資料。

## Process

1. 保留原文，不覆寫 raw。
2. 建立 source summary。
3. 抽出 concepts。
4. 每個 concept 連回 source。
5. 僅把長期有用的決策資訊寫入 memory。
6. 對不確定資訊標示待驗證。

## Output Standard

每份 source summary 至少包含：

- Source path
- Ingested time
- Concepts
- Extracted points
- Verbatim anchor
- Open questions
