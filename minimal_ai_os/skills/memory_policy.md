# Skill: Memory Policy

## Purpose

決定哪些資訊可以進入長期 memory，哪些只能留在 raw、wiki 或 artifacts。

## Save To Memory When

- 未來 3 個月以上仍可能重複使用。
- 能降低未來決策成本。
- 是穩定偏好、長期流程、核心原則、專案架構或固定限制。
- 已經從原文或多次互動中確認，不是單次猜測。

## Do Not Save When

- 只是暫時任務。
- 是未驗證傳聞。
- 是一次性摘要。
- 是高敏感個資或不必要的私人細節。
- 只是模型推論，沒有來源或使用者確認。

## Memory Entry Format

```md
## YYYY-MM-DD — Title
- Type: preference | project | process | constraint | decision
- Source: raw/wiki/artifact path
- Content:
- Review date:
```
